# 04. Saju Calculation Specification (사주 계산 규격서)

> **문서 버전**: 1.0.0
> **작성 일자**: 2026년 9월 20일
> **상태**: 확정 (Approved)
> **적용 모듈**: src/destiny_saju/calculator/

## 1. 개요
NormalizedBirthProfile을 받아 4주 8자(또는 3주 6자) 및 대운/세운을 산출한다.

## 2. 절기 기준 간지 계산
- 연주/월주 변경: 입춘 및 12개 절입 시각(분 단위) 기준. 1900~2050 KASI 절기 JSON 테이블 조회.
- 절기 경계일 + 시간 미상: 사용자 시간대 유도, 미상 유지 시 절기 전/후 간지 후보 2개 분기 제공.

## 3. 자시 및 일주 경계
- 기본(Default): 00:00 자정 기준 일진 변경(조자시)
- 전문가 설정: 23:00 기준 일진 변경(정자시)

## 4. 대운 계산 규칙
- 순행/역행: 양남음녀 순행, 음남양녀 역행
- 대운수: (절기와 출생시 사이 일수) / 3 공식, 소수점 정밀 보존 및 반올림 정수(1~10) UI 표기
- 시간 미상 시 정오(12:00) 기준 앵커 계산 및 오차 플래그 표기
