# 03. BirthProfile Specification (출생정보 정규화 규격서)

> **문서 버전**: 1.1.0
> **작성 일자**: 2026년 9월 20일
> **상태**: 확정 (Approved)
> **적용 모듈**: src/destiny_saju/birth/

## 1. 개요 및 설계 철학
사용자로부터 입력받은 출생 정보를 정규화 데이터(NormalizedBirthProfile)로 변환한다.
- 원본 보존: Raw input 불변
- 추측 금지: 모르는 정보는 AI가 임의 추정 금지
- 자동화 우선: 100% 자동 판단 가능한 항목은 보정, 모호하면 명시적 선택 요청

## 2. 데이터 스키마
- RawBirthInput: calendar_type(solar/lunar), birth_year, birth_month, birth_day, birth_time_str, is_leap_month, gender, location_text
- NormalizedBirthProfile: profile_id, raw_input, normalized_utc_timestamp, solar_birth_date, base_timezone, historical_dst_applied, dst_offset_minutes, meridian_offset_minutes, adjusted_solar_time, time_precision, analysis_mode, applied_rule_ids, resolution_status

## 3. 핵심 정규화 정책
1. 윤달 자동 판정: 윤달 없는 달은 false 자동화, 윤달 공존 시 선택 유도(모름 시 평달/윤달 후보 2개 분기)
2. 서머타임(DST) 자동 보정: 아래 3.1의 연도별 12구간에 해당하면 -60분 자동 보정(규칙 ID `DST_APPLIED_MINUS_60`)
3. 표준 자오선 시차 보정: 127.5도 구간(1908~1911, 1954~1961) 0분, 135도 구간(1912~1954, 1961~현재) -30분 자동 보정
4. 시간 미상(Unknown Time): 임의 시간 대입 금지, 3주 분석 모드(analysis_mode=THREE_PILLARS) 전환 및 시주 null 처리

### 3.1 서머타임(DST) 적용 구간

서머타임은 매년 여름에만 시행되었으므로 연속 구간이 아니라 **연도별 12구간**으로 관리한다.
시작일과 종료일은 **양 끝 모두 포함(inclusive)** 이며, `종료일`은 시계가 되돌아간 날이 아니라
**서머타임이 적용된 마지막 날**이다.

| 연도 | 시작일 | 종료일 | 기준 자오선 | 서머타임 중 벽시계 오프셋 |
| --- | --- | --- | --- | --- |
| 1948 | 1948-06-01 | 1948-09-12 | 135°E (UTC+09:00) | UTC+10:00 |
| 1949 | 1949-04-03 | 1949-09-10 | 135°E (UTC+09:00) | UTC+10:00 |
| 1950 | 1950-04-01 | 1950-09-09 | 135°E (UTC+09:00) | UTC+10:00 |
| 1951 | 1951-05-06 | 1951-09-08 | 135°E (UTC+09:00) | UTC+10:00 |
| 1955 | 1955-05-05 | 1955-09-08 | 127.5°E (UTC+08:30) | UTC+09:30 |
| 1956 | 1956-05-20 | 1956-09-29 | 127.5°E (UTC+08:30) | UTC+09:30 |
| 1957 | 1957-05-05 | 1957-09-21 | 127.5°E (UTC+08:30) | UTC+09:30 |
| 1958 | 1958-05-04 | 1958-09-20 | 127.5°E (UTC+08:30) | UTC+09:30 |
| 1959 | 1959-05-03 | 1959-09-19 | 127.5°E (UTC+08:30) | UTC+09:30 |
| 1960 | 1960-05-01 | 1960-09-17 | 127.5°E (UTC+08:30) | UTC+09:30 |
| 1987 | 1987-05-10 | 1987-10-10 | 135°E (UTC+09:00) | UTC+10:00 |
| 1988 | 1988-05-08 | 1988-10-08 | 135°E (UTC+09:00) | UTC+10:00 |

기준 자오선 열은 3항의 표준 자오선 구간(1912-01-01~1954-03-20 및 1961-08-10~현재는 135°E,
1954-03-21~1961-08-09는 127.5°E)과 대조해 채운 값이다.

#### 1987·1988년 전환 시각과 경계 근사

1948~1960년 구간은 시계가 **00:00**에 전환되어 날짜 단위 표로 정확히 표현된다.
반면 1987·1988년은 **시작 02:00, 종료 03:00**에 전환되어 날짜 단위로는 전환 순간을 표현할 수 없다.
따라서 해당 구간의 시작일과 종료 다음 날에는 규칙 ID `DST_BOUNDARY_DATE_APPROXIMATE`를 부여해
그 날짜의 서머타임 적용 여부가 날짜만으로 확정되지 않음을 결과에 명시한다.

- 대상 날짜: 1987-05-10, 1987-10-11, 1988-05-08, 1988-10-09
- 해당 날짜 중 최대 2~3시간 구간은 표의 값과 실제 시행 상태가 다를 수 있다.

#### 정본과 검증 상태

- **이 표의 정본은 `src/destiny_saju/birth/civil_time.py`의 `DST_PERIODS`이다.** 문서와 구현이
  어긋나면 구현을 기준으로 삼고 이 문서를 갱신한다.
- 각 날짜는 국가기록원 서머타임 기록과 IANA `Asia/Seoul` 존 데이터를 근거로 입력되었으나,
  **pinned tzdata 릴리스 대조 검증은 아직 완료되지 않았다.**
- 민간시 해석 정책과 전환 구간 테스트 계획은 [docs/53_KOREAN_HISTORICAL_CIVIL_TIME_POLICY.md](53_KOREAN_HISTORICAL_CIVIL_TIME_POLICY.md)를 참조한다.
  53번은 정책·테스트 계획 문서이며, 위 구간 날짜를 확정한 근거 문서가 아니다.
