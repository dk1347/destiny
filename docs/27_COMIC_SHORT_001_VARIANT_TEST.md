# Destiny — Comic Short 001 Variant Test

> Status: internal pre-publication test plan. It does not authorize posting,
> account actions, paid promotion, or collection of personal data.

## Objective

Compare whether the paired male- and female-protagonist versions of Comic
Short 001 earn different voluntary attention among the available early
audience. This is a format/creative test, not a claim about a gender's
universal popularity.

## Fixed inputs

| Item | Fixed value |
| --- | --- |
| Topic | `출생시간을 모르면 사주를 못 볼까?` |
| Storyboard | Five cuts from `docs/26_COMIC_SHORT_001_BIRTH_TIME_UNKNOWN.md` |
| Duration | 18–25 seconds |
| Spoken copy and Korean captions | The approved Comic Short 001 script |
| CTA | `계산 기준 알아보기` or, until a destination is approved, `Destiny 개발 중` |
| Safety boundary | No fortune promise, personal reading, financial claim, fear appeal, or request for birth data |
| Asset pair | `web/public/content/comic-short-001-storyboard-v1.png` and `web/public/content/comic-short-001-storyboard-female-v1.png` |

## Variables and release order

Only protagonist presentation differs between the two masters. Do not change
the title, copy, music, edit pace, hashtags, CTA, or destination while making
the first comparison.

Avoid publishing both variants to the same audience at the same moment. The
initial organic run uses counterbalanced order:

| Platform | First release | Second release | Minimum gap |
| --- | --- | --- | --- |
| Instagram Reels | male version | female version | 7 days |
| TikTok | female version | male version | 7 days |

The publication time should be kept within the same two-hour window for each
platform when feasible. Record the actual time; do not treat it as controlled
if it differs materially.

## What to record

Record each platform's own measures after 48 hours and again after 7 days:

- reach or feed impressions;
- views and completion/read-through measure available on that platform;
- saves, shares, likes, and moderated non-spam comments;
- profile visits and qualified destination visits, only if an approved
  destination exists;
- production time and any edit differences;
- publication time, final caption, audio, and hashtag version.

Never request or record birth date, birth time, gender, or other personal data
in comments or direct messages for this test.

## Decision rule

Do not choose a permanent character direction from one post or raw view count.
Use a direction only if the same variant shows repeated improvement in a
primary consumption signal or save/share signal across both platforms without
raising a moderation, trust, or production-cost concern. Otherwise mark the
result `inconclusive` and test a different topic or visual treatment.

## Required approval before publishing

The product owner must approve the final video renders, caption, account used,
CTA destination, comment response policy, and publication timing before either
variant is posted.
